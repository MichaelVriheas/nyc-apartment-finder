# NYC Apartment Finder

A personal apartment-search dashboard for an August 2027 move near Columbia University.

**Filters:** Studio or one-bedroom; monthly advertised base rent at most $3,000; Morningside Heights, Manhattan Valley, Manhattanville, Hamilton Heights, South Harlem, Northern Upper West Side, Central Harlem, Washington Heights, and Fort Lee NJ.

**Data caveat:** Initial free FirstMover monthly rental snapshots are historical and must not be described as currently available listings. Fort Lee coverage may be limited.

The initial site, data refresh script, and GitHub Actions deployment will be added here.
